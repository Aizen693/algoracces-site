Double authentification

Un code à usage unique, affiché par une application sur votre téléphone, s’ajoute au mot de passe à chaque connexion.

  1. Ouvrez votre application d’authentification (Google Authenticator, Microsoft Authenticator, FreeOTP…) et scannez ce code.
  2. Si vous ne pouvez pas scanner, saisissez la clé à la main.
  3. Entrez le code à 6 chiffres affiché par l’application.
